# Pitman–Yor prior for a latent partition

Pitman–Yor prior for a latent partition

## Usage

``` r
pitman_yor_prior(concentration = 1, discount = 0.2)
```

## Arguments

- concentration:

  Concentration parameter.

- discount:

  Discount parameter in `[0, 1)`.

## Value

An object of class `btsbm_partition_prior`.

# Run Pareto-smoothed importance-sampling LOO for a fit

Run Pareto-smoothed importance-sampling LOO for a fit

## Usage

``` r
loo_btsbm(fit, ...)
```

## Arguments

- fit:

  A `btsbm_fit` object.

- ...:

  Passed to [`loo::loo()`](https://mc-stan.org/loo/reference/loo.html).

## Value

A `loo` object.
